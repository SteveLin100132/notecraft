文字講不清楚的內容，可以在筆記中放一個 `@ai-visualize` 標記，描述想要的互動元件，再交給 AI 產生。本篇示範三種已生成的元件、待生成標記的樣貌，以及外掛提供的資料檔。

## AI 視覺化標記

標記寫在 MDX 註解裡，不會出現在發佈後的頁面。`id` 決定產生的檔名，`type` 為元件類型，`prompt` 描述需求，`status` 記錄生成狀態。

```mdx
{/* @ai-visualize
id: my-leave-calculator
type: free
prompt: |
  把特休年資級距做成可拖曳的計算器，顯示天數與級距說明。
status: pending
*/}
```

生成後，元件會以統一的外框呈現：左上為類型，右上為元件檔案路徑與放大按鈕。

## Renderer Plugin

AI 元件是為一篇筆記量身產生的；renderer plugin 則負責某一類**資料檔**，例如資料庫 schema 或 API 規格。資料檔更新後重新建置，所有用到它的地方都會跟著更新。

### 對應資料檔

在 `.notecraft/plugins.json` 以 glob 指定每個 plugin 負責哪些檔案。符合的檔案會自動產生獨立檢視頁，並出現在側欄的「Plugin」。

```json title=".notecraft/plugins.json"
{
  "plugins": [
    { "plugin": "er-diagram-renderer", "files": ["**/*.er.json"] },
    { "plugin": "openapi-renderer", "files": ["**/*.openapi.json"] }
  ]
}
```

| Plugin | 負責的檔案 | 渲染結果 |
| --- | --- | --- |
| `er-diagram-renderer` | `**/*.er.json` | 把資料庫 schema JSON 渲染成 Schema／Table 導覽、Wiki 與可聚焦、可搜尋的實體關聯圖 |
| `openapi-renderer` | `**/*.openapi.json` | 把 OpenAPI 3.x 規格渲染成依標籤分組的 API 文件與可複製的請求範例 |

### 嵌入筆記

資料檔除了有自己的檢視頁，也可以用 `<PluginView>` 直接嵌入筆記，嵌入時由同一個 renderer 以精簡模式呈現；需要時可用 `options` 覆寫這一處的設定。

```mdx
import PluginView from "@/components/PluginView.astro";

<PluginView src="schema-demo.er.json" />
```

:::note
嵌入與檢視頁讀的是同一份資料檔，不會複製內容到筆記裡。系列也可以把資料檔當成一個章節，本系列的最後一章就是這份 ER 圖。
:::
