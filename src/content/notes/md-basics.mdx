本篇整理 NoteCraft 支援的標準 Markdown（CommonMark 與 GitHub Flavored Markdown）。每一節先列出寫法，再直接呈現渲染結果。MDX 擴充語法，例如 :ref[定義區塊]{id="nc.syntax-define"}、提示框與分頁，請見系列下一章「進階語法」。

## 標題

以 1 到 6 個 `#` 開頭。H1 保留給筆記標題，內文從 H2 開始；H2 與 H3 會列入右側目錄，H4 以下只用來切分段落。

```markdown
## 第二層標題
### 第三層標題
#### 第四層標題
```

### 第三層標題

第三層標題會列入目錄，並縮排在所屬的 H2 之下。

#### 第四層標題

第四層以下不列入目錄。

##### 第五層標題

較少使用，通常出現在規格的欄位說明。

###### 第六層標題

最小的標題層級。

## 段落與行內樣式

段落之間以一個空行分隔。行內可以混用 **粗體**、*斜體*、~~刪除線~~、==螢光標記==、上標 x<sup>2</sup>、下標 H<sub>2</sub>O、鍵盤按鍵 <kbd>⌘</kbd> <kbd>K</kbd>、行內程式碼 `npm run dev`、[站內連結](/notes/md-advanced)，以及徽章 :badge[v2.3] :badge[Beta]{variant="info"}。

```markdown
**粗體**、*斜體*、~~刪除線~~、==螢光標記==
x<sup>2</sup>、H<sub>2</sub>O、<kbd>⌘</kbd> <kbd>K</kbd>、`npm run dev`
[站內連結](/notes/md-advanced)、:badge[Beta]{variant="info"}
```

## 清單

### 無序清單

- 以 `-` 或 `*` 開頭
  - 縮排兩個空格建立子清單
  - 子清單可以再包含段落與程式碼
- 清單項目之間不需要空行

### 有序清單

1. 以數字加句點開頭。
2. 實際編號由渲染器自動產生，原始檔可全部寫 `1.`。
3. 中間插入段落時，編號會自動接續。

### 待辦清單

以 `- [ ]` 與 `- [x]` 標示，點擊方框可切換狀態（只影響閱讀畫面，不會寫回檔案）。

- [x] 建立筆記與 frontmatter
- [x] 補上標題層級與段落
- [ ] 加入表格與程式碼範例
- [ ] 發佈前檢查連結

## 引言

以 `>` 開頭；連續兩個 `>>` 為巢狀引言，最後一行可以加上出處。

> 好的筆記不是把資料抄下來，而是把自己的理解寫清楚，讓三個月後的自己也看得懂。
>
> > 寫作是思考的延伸；寫不清楚的地方，通常就是還沒想清楚的地方。
> >
> > <cite>寫作課講義</cite>
>
> <cite>NoteCraft 寫作指南</cite>

## 表格

以 `|` 分隔欄位，第二列的冒號決定對齊方式。表格過寬時可以左右捲動。

| 語法 | 用途 | 列入目錄 | 建議數量 |
| --- | --- | :---: | ---: |
| `##` | 章節標題 | 是 | **3–8** |
| `###` | 小節標題 | 是 | 0–4 / 章 |
| `####` | 段落標題 | 否 | 不限 |
| `---` | 主題轉換的分隔線 | — | 少用 |

## 程式碼區塊

以三個反引號包住程式碼，並標註語言。可以加上檔名，並以 `{5}` 標示要強調的行。

```ts title="notecraft.config.ts" {5}
import { defineConfig } from "notecraft";

export default defineConfig({
  contentDir: "src/content/notes",
  toc: { minLevel: 2, maxLevel: 3 },
  readingSpeed: 450,
});
```

語言標為 `diff` 時，以 `+` 與 `-` 開頭的行會分別標示為新增與刪除：

```diff title="notecraft.config.ts" lang=ts
 toc: {
-  maxLevel: 4,
+  maxLevel: 3,
 },
+readingSpeed: 450,
```

## 分隔線、定義清單與註腳

三個連字號 `---` 產生分隔線，用於段落主題轉換：

---

定義清單以 `:::dl` 包住一個清單，每一項以粗體的名詞開頭，冒號後面是說明：

:::dl
- **Frontmatter**：檔案開頭以 `---` 包住的 YAML，記錄標題、標籤與狀態。
- **Slug**：由檔名產生的網址片段，例如 `md-basics`。
- **MDX**：可以在 Markdown 中使用元件的格式，NoteCraft 的擴充語法都建立在它之上。
:::

註腳以 `[^1]` 標記，內容統一列在文末[^1]；點註腳編號可跳到說明，再點 ↩ 回到內文[^2]。

[^1]: 註腳內容可以寫在檔案任何位置，渲染時一律移到文末。

[^2]: 同一個註腳被多處引用時，編號只會出現一次。
