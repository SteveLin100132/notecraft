這篇測 `openapi-renderer` 的內嵌模式：外框由 app 提供（只有一層）、`options.operation` 指定要看哪一支、`anchor` 讓「開啟完整檢視頁」直接到那一支。

## 單一 operation：建立訂單

<PluginView src="testing/openapi/orders.openapi.json" options={{ operation: "createOrder" }} anchor="op/createOrder" />

## 單一 operation：列出訂單

同一份 spec 在同一篇筆記內嵌第二次，按 Esc、點目錄錨點都不該互相干擾。

<PluginView src="testing/openapi/orders.openapi.json" options={{ operation: "listOrders" }} anchor="op/listOrders" />

## 總覽縮影

沒有指定 `operation` 時，顯示整份 API 的 tag 清單，點一列到文件頁的該 tag。

<PluginView src="testing/openapi/petstore.openapi.json" />

## 找不到 operation

`operation` 打錯時，卡片內顯示錯誤，不會讓 build 失敗。

<PluginView src="testing/openapi/orders.openapi.json" options={{ operation: "nope" }} />
