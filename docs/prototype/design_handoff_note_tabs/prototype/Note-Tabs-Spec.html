NOTECRAFT 工作台 ・ 功能設計

筆記頁籤

讀者可同時開啟多份筆記與資料檔渲染頁，在主區最上方的頁籤列切換，不必回列表或 Sidebar 重找。網站是 Astro 靜態 MPA，所以頁籤是一份存在 localStorage 的「已開啟清單」：每次換頁重畫頁籤列，切回某頁籤時還原上次的捲動位置。

下方畫面都是工作台 Prototype 的實際渲染（以 ?tabsDemo= 參數帶入示範資料，不寫入你的 localStorage）。開啟 Prototype 可直接操作：雙擊列表開頁籤、右鍵、拖曳、⌥ , ⌥ . 切換。

04互動規則

位置與麵包屑

頁籤列放在主區最上方、Header 之上。麵包屑保留不簡化：頁籤只顯示標題，資料夾位置（NoteCraft / 筆記 / 01-前端）仍需要麵包屑提供，且麵包屑是回到資料夾列表的唯一一鍵入口。兩者分工是「頁籤 = 我開了什麼」、「麵包屑 = 這篇在哪裡」。

開啟與聚焦

  • 所有開啟入口（列表雙擊、列上「開啟」、Drawer「開啟筆記」、Sidebar、⌘K、Dashboard 列、資料檔列）走同一個規則：同一網址已有頁籤就聚焦它，否則在目前 active 的右側插入新頁籤（不在頁籤頁時加到最後）。
  • 頁籤的 key 是 note:{slug} 或 view:{id}。系列、標籤、Dashboard、Plugin 列表、設定頁不開頁籤。
  • 關閉 active 頁籤時導覽到右鄰，沒有右鄰就左鄰；最後一個也關了就回 /notes。
  • 中鍵點頁籤 = 關閉。固定頁籤不能用 ✕ 或 ⌥ W 關閉，需先取消固定。

關閉 ✕：active 常駐，其他 hover 才出現

與 VS Code 相同的折衷。15 個頁籤時每個都有 ✕ 會很吵，也容易誤關；active 常駐是因為「看完這篇就關」是最常見的動作。✕ 的位置在隱藏時仍佔位，hover 時標題不會跳動。觸控裝置（pointer: coarse）一律常駐。

不做預覽頁籤

單擊列已經會開 Drawer 預覽，Drawer 就是本工作台的「暫時檢視」。若再加斜體暫時頁籤，單擊會同時觸發兩種預覽，且 MPA 下暫時頁籤每次都要整頁導覽，比 Drawer 慢得多。所以規則是：單擊 = Drawer，開啟 = 固定的一般頁籤。

溢出：捲動＋全部頁籤下拉＋20 個上限

  • 頁籤先收縮到 120px，再改水平捲動，左右漸層遮罩提示還有內容。
  • 尾端「N ▾」常駐，點開是可篩選的全部頁籤清單；數量少時也保留，位置穩定。
  • 未固定頁籤上限 20。開第 21 個時自動關閉「最久未切換」的未固定頁籤，toast 告知標題，並可用 ⌥ ⇧ T 重開。固定頁籤不計入上限。

狀態小點：預設不顯示

頁籤上已有 icon、標題、✕／圖釘，再加閱讀狀態或 AI 待生成點會和 ✕ 搶視線，而且這兩種資訊在 Header 的 pill 已經看得到。建議預設關閉，改放在頁籤的 tooltip（標題、路徑、待生成數）。Prototype 的 Tweaks「頁籤狀態點」可切換 AI 待生成／閱讀狀態兩種版本比較。

刪除筆記（dev-only）

刪除成功後關閉對應頁籤（不進「最近關閉」堆疊），active 規則同一般關閉。若是在別處刪除、或 build 後檔案消失，下次渲染頁籤列時清掉解析不到的頁籤，toast「筆記已不存在，對應頁籤已關閉」。

⌘K Palette

最上方新增「已開啟的頁籤」分區（無查詢時列 6 個，有查詢時最多 4 個相符），目前頁面標「目前」，固定標「已固定」。Enter 優先選頁籤。

拖曳排序

只在 pointer: fine 裝置啟用 HTML5 drag，與 Board 規則一致。固定與一般頁籤各自排序，不能跨區拖。觸控裝置不提供；手機的清單抽屜也不排序。

05鍵盤與語意

動作快捷鍵說明
下一個／上一個頁籤⌥ . ／ ⌥ ,循環切換。不在頁籤頁時，任一鍵回到最後讀的那篇。
關閉目前頁籤⌥ W固定頁籤不作用。
重開剛關閉的⌥ ⇧ T最近 10 筆，連同捲動位置一起還原。
全部頁籤⌘K 後直接看「已開啟的頁籤」不另佔快捷鍵。

⌘W／⌘T／⌘數字／⌃Tab 會被瀏覽器攔走，所以用 Option（Windows 為 Alt）。實作要比對 event.code（Comma、Period、KeyW、KeyT），因為 macOS 的 Option 會把 event.key 變成特殊字元。輸入框內不攔截。

頁籤列：role="tablist" + aria-label="已開啟的頁籤"；每個頁籤 role="tab"，目前頁面 aria-selected="true"，主區 Body 是對應的 tabpanel。roving tabindex：只有一個頁籤 tabindex=0（預設 active，否則第一個），← → 移動焦點、Home End 跳頭尾、Enter 開啟、Delete 關閉、⇧ F10 開右鍵選單。✕ 按鈕 tabindex=-1，以 Delete 取代。

06MPA 落地

  • 資料：localStorage["nc.tabs.v1"] = { tabs: [{ kind, id, key, pinned, scroll, at }], closed: [...] }。標題、路徑在渲染時從 build 產出的筆記索引解析，不存 localStorage，避免改名後顯示舊標題。
  • SSR 佔位：Astro layout 輸出一個空的 34px .nt-bar（手機寬度 display:none），island 以 client:load 讀 localStorage 後補上頁籤。空清單時顯示提示文字，高度不變，所以 hydrate 前後零位移。
  • 捲動還原：Body 捲動時 debounce 220ms 寫入目前頁籤的 scroll；pagehide 再補寫一次。新頁面 hydrate 後在下一個 frame 設定 scrollTop（等 MDX 圖表撐開高度）。
  • 多分頁同步：監聽 storage 事件，其他瀏覽器分頁增減頁籤時重畫。
  • 在新視窗開啟：直接 window.open(url)，新視窗共用同一份清單。

07待決問題

Q1頁籤上是否顯示狀態小點？
建議：不顯示，資訊放 tooltip。次選：只顯示 AI 待生成（橘點），閱讀狀態不顯示。Tweaks 可比較。
Q2未固定頁籤上限是否定在 20？
建議：20，超過自動關最久未用的，並 toast 告知。次選：不設上限，只靠捲動與下拉。
Q3快捷鍵用 ⌥ , / ⌥ . 是否可接受？
建議：⌥ , ／ ⌥ .（與 ⌘K 不衝突、不被瀏覽器攔截）。次選：⌥ [ ／ ⌥ ]，與 VS Code 的方括號直覺較接近，但部分鍵盤配置需按 Shift。另需確認是否加 ⌥ 1–9 跳第 N 個（Linux Firefox 會攔截 Alt+數字）。
Q4新頁籤插入位置？
建議：插在 active 右側（從一篇跳到相關筆記時兩者相鄰）。次選：一律加在最後，順序較好預測。
Q5系列詳情頁要不要也能開頁籤？
建議：暫不開，系列頁是導覽頁，讀者主要停留在章節筆記。若之後觀察到常在系列頁與章節間來回，再加 series:{id}。
Q6簡報模式（全螢幕 Present／版型庫）是否顯示頁籤列？
建議：不顯示，維持現在全螢幕不帶殼的行為；離開簡報回到原頁籤。
