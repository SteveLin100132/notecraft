表中 Mac 與 Windows／Linux 寫法不同時分兩欄；相同時只寫一次。`⌥` 在 Windows／Linux 是 `Alt`。

## 全域

工作台的每一頁都有，簡報頁 `/present/…` 除外。

| Mac | Windows／Linux | 作用 | 備註 |
| :-- | :-- | :-- | :-- |
| `⌘K` | `Ctrl+K` | 開啟[指令面板](/docs/guides/palette/) | Mac 上 `Ctrl+K` 也可以；輸入框裡一樣有效 |
| `⌥.` | `Alt+.` | 下一個頁籤 | 到尾端繞回第一個 |
| `⌥,` | `Alt+,` | 上一個頁籤 | |
| `⌥W` | `Alt+W` | 關閉目前的頁籤 | 固定的頁籤不會被關 |
| `⌥⇧T` | `Alt+Shift+T` | 重開剛關閉的頁籤 | 最多記 10 個 |
| `Esc` | `Esc` | 關閉最上層的浮層 | 見下方「Esc 的順序」 |

頁籤快捷鍵以實體按鍵位置判斷，Mac 上 `⌥` 組合鍵打出特殊符號也不影響。游標在輸入框、文字區、下拉選單或可編輯區塊裡時，這四組按鍵不會被攔下。

## 指令面板

| 按鍵 | 作用 |
| :-- | :-- |
| `↑` `↓` | 在結果之間移動 |
| `Enter` | 開啟選中的項目 |
| `⌘`／`Ctrl`＋`Enter` | 在新的瀏覽器分頁開啟 |
| `Esc` | 關閉面板 |

注音、拼音選字中的 `Enter` 不會觸發開啟。

## 列表、儀表板與 Drawer

適用 `/notes` 四種檢視的列與卡片，以及儀表板的最近更新、更新日誌與更新月曆。

| 按鍵 | 作用 |
| :-- | :-- |
| `Space` | 開關右側 Drawer 預覽 |
| `Enter` | 進入筆記 |
| `⌘`／`Ctrl`＋`Enter` | 在新的瀏覽器分頁開啟筆記 |
| `↑` `↓` | 移到上一列／下一列，收合的群組會跳過 |
| `Esc` | 關閉 Drawer |

Drawer 開著時，`Tab` 只在 Drawer 裡循環。

頁首的分頁（例如儀表板的總覽／更新月曆／AI 佇列）與 Toolbar 的切換鈕，在焦點上時可以用 `←` `→` 切換。

## 筆記頁籤列

焦點在頁籤列的某個頁籤上時：

| 按鍵 | 作用 |
| :-- | :-- |
| `←` `→` | 移到左右的頁籤，頭尾相接 |
| `Home`／`End` | 跳到第一個／最後一個頁籤 |
| `Space` | 切換到該頁籤 |
| `Delete`／`Backspace` | 關閉該頁籤（固定的不會被關） |
| `⇧F10`、選單鍵 | 開右鍵選單 |

右鍵選單與「全部頁籤」下拉裡可以用 `↑` `↓` 移動。「全部頁籤」的篩選框按 `Enter` 開第一個結果、按 `↓` 進入清單。詳見[筆記頁籤](/docs/guides/tabs/)。

## 放大檢視

元件或內嵌資料檔開在全螢幕畫布時（見[放大檢視與匯出 PNG](/docs/guides/zoom/)）：

| 按鍵 | 作用 | 備註 |
| :-- | :-- | :-- |
| `+`／`-` | 放大／縮小 | 指標在畫布上時 |
| `0` | 還原置中 | 指標在畫布上時 |
| `Esc` | 回到筆記 | 先於其他浮層處理 |

## 簡報

`/present/<slug>` 的按鍵，詳細說明見[播放與快捷鍵](/docs/guides/deck-play/)。

| 模式 | 按鍵 | 作用 |
| :-- | :-- | :-- |
| 檢視 | `→` `↓` | 下一頁 |
| 檢視 | `←` `↑` | 上一頁 |
| 檢視 | `Enter` | 從目前這一頁開始播放 |
| 播放 | `→` `↓` `Space` | 下一頁 |
| 播放 | `←` `↑` | 上一頁 |
| 播放 | `O` | 開關大綱 |
| 播放 | `Esc` | 大綱開著時關閉大綱，否則結束播放 |
| 兩者 | `+`／`-`／`0` | 投影片上的畫布放大／縮小／還原置中（指標在畫布上時） |

瀏覽器進入全螢幕時，`Esc` 可能先被瀏覽器拿去離開全螢幕，播放也隨之結束。

## 官方 plugin 頁

### ER Diagram Renderer

| 按鍵 | 作用 | 備註 |
| :-- | :-- | :-- |
| `←` `→` | 切換 Wiki／Diagram 分頁、切換 Diagram 範圍 | 焦點在分頁或範圍按鈕上時 |
| `+`／`-` | 放大／縮小圖 | 焦點在 Diagram 畫布上時 |
| `0` | 還原圖的位置與縮放 | 同上 |
| `Esc` | 一次退一層：取消圖上的聚焦或提示 → 關閉窄螢幕的覆蓋導覽 → 離開全寬 | 焦點要在這張圖裡（全寬時不限） |

內嵌在筆記裡也適用。同一篇筆記有兩張圖時，只有焦點所在的那張會反應。

### OpenAPI Renderer

只在資料檔頁 `/view/…` 有效，內嵌在筆記裡的卡片不處理按鍵。端點不超過 4 個、也沒有分 tag 的小型文件，沒有 `/` 與 `Esc` 這兩組。

| 按鍵 | 作用 | 備註 |
| :-- | :-- | :-- |
| `/` | 聚焦導覽的篩選框，窄螢幕時先打開導覽 | 游標在輸入框裡時不攔 |
| `Esc` | 一次退一層：關閉窄螢幕的覆蓋導覽 → 清除文字篩選 → 清除 method 篩選 → 離開篩選框 → 收起所有展開項 | |
| `←` `→` | 切換回應狀態碼、content type、cURL／fetch | 焦點在這些切換鈕上時 |

## Esc 的順序

一次 `Esc` 只關一層：

<EscStack />

1. **放大檢視**最先處理；裡面是 ER 圖而且圖上有聚焦或提示時，先取消那些，再按一次才關放大檢視
2. **工作台的浮層**（指令面板、Drawer、頁籤選單、手機的 Sidebar 抽屜…）疊成一疊，關最後打開的那一個
3. **OpenAPI 頁**的逐層退排在最後：前面有人處理過這次 `Esc`，它就不動。例如篩選中開 `⌘K` 再按 `Esc`，只會關掉面板，篩選字保留
