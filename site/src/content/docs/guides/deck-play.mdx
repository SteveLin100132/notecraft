有簡報的筆記，頁首與 Drawer 的「簡報」按鈕會連到 `/present/<slug>`。這一頁不在工作台裡，沒有 Rail 與 Sidebar，整個視窗都給投影片。`view` 與 `build`／`serve` 的產物都能用。

## 兩種模式

| 模式 | 畫面 | 怎麼進入 |
| :-- | :-- | :-- |
| 檢視 | 上方標題列、左側縮覽清單、中間一頁投影片與左右翻頁按鈕 | 打開 `/present/<slug>` 就是 |
| 播放 | 投影片放到最大，底部有頁碼、「大綱 / 跳頁」與「結束播放」 | 按標題列的「播放（全螢幕）」或 `Enter` |

檢視模式的標題列還有：

- 「返回筆記」：回到 `/notes/<slug>`
- 亮色／暗色切換：選擇會記在瀏覽器裡，下次打開沿用；沒選過時跟著系統的深色模式設定
- 目前頁碼，例如 `3 / 12`

網址的 hash 記著目前頁碼（`#3` 是第 3 頁），重新整理不會回到第一頁，也可以直接分享某一頁的連結。

## 進出全螢幕

按「播放（全螢幕）」或 `Enter` 會從目前這一頁開始播放，並要求瀏覽器進入全螢幕。瀏覽器不支援或拒絕全螢幕時，播放畫面改成蓋滿整個視窗，其他操作不變。

退出播放有三種方式：

- 按 `Esc`
- 按底部的「結束播放」
- 用瀏覽器自己的方式離開全螢幕，播放會跟著結束

按「結束播放」退出時，檢視模式會停在你播放到的那一頁。

## 快捷鍵

### 播放模式

| 按鍵 | 動作 |
| :-- | :-- |
| `→`、`↓`、`Space` | 下一頁 |
| `←`、`↑` | 上一頁 |
| `O` | 開關大綱 |
| `Esc` | 大綱開著時關閉大綱；否則結束播放 |

瀏覽器真的進入全螢幕時，`Esc` 可能先被瀏覽器拿去離開全螢幕，播放也隨之結束。這時想只關大綱，點大綱的「關閉」或大綱以外的地方。

剛進入播放時，上方會短暫浮出按鍵提示，約 3 秒後淡出。畫面左右兩側也有翻頁按鈕，到第一頁或最後一頁時會變淡。

大綱從底部升起，列出所有投影片的縮圖，點一張就跳到那一頁並關閉大綱。點大綱以外的地方也會關閉。

### 檢視模式

| 按鍵 | 動作 |
| :-- | :-- |
| `→`、`↓` | 下一頁 |
| `←`、`↑` | 上一頁 |
| `Enter` | 從目前這一頁開始播放 |

也可以直接點左側縮覽清單的任一頁。

## 互動元件怎麼操作

沿用自筆記的 `@ai-visualize` 元件放在一塊可縮放、平移的畫布上（見[簡報](/docs/guides/deck/)）。畫布刻意不用翻頁、大綱與退出用的那幾個鍵，所以兩邊不會搶按鍵。

| 操作 | 檢視模式 | 播放模式 |
| :-- | :-- | :-- |
| 縮放 | `⌘`／`Ctrl`＋滾輪，或觸控板捏合 | 直接滾輪，或觸控板捏合 |
| 水平平移 | `Shift`＋滾輪 | `Shift`＋滾輪 |
| 平移 | 從元件外的空白處拖曳 | 同左 |
| `+`／`-`／`0` | 放大／縮小／還原置中（指標在畫布上時） | 同左 |

縮放範圍 25%–300%。畫布底部的控制列也有縮小、放大與還原置中。

- 在元件上點擊、拖曳，交給元件本身：按鈕照樣能按、滑桿照樣能拖。想從元件上起手平移畫布，按住 `⌥`／`Alt` 再拖
- 檢視模式下沒按 `⌘`／`Ctrl` 的滾輪不會縮放畫布；縮放已到上下限時，滾輪也不再被畫布攔下

<Callout>
投影片上沒有滑鼠懸停可依賴，所以生成簡報時，圖表的數值會直接標在圖上，不只放在 tooltip 裡。
</Callout>

## 手機與觸控

簡報頁沒有滑動翻頁的手勢，也沒有另外的手機版面。在觸控裝置上，用畫面上的左右箭頭按鈕翻頁，播放模式用「大綱 / 跳頁」跳到指定頁。

## 沒有簡報時

`/present/<slug>` 只會為已經生成簡報的筆記產生頁面。筆記還沒有簡報時，這個網址是 404，筆記頁首也不會出現「簡報」按鈕。在 `view` 模式下，同一個位置是「生成簡報」，它會把提示詞複製到剪貼簿，怎麼用見[簡報](/docs/guides/deck/)。
