系列要先在 `series.json` 定義，寫法見[系列設定](/docs/getting-started/series/)。這頁講讀的人看到什麼、怎麼操作。

## 三種閱讀狀態

| 狀態 | 怎麼變成這樣 |
| :-- | :-- |
| 未開始 | 預設值 |
| 閱讀中 | 打開一篇未開始的筆記時自動切換，不會從已完成降回來 |
| 已完成 | 自己標記 |

改狀態的地方：

- **筆記頁首**的三段切換：未開始／閱讀中／已完成，可以任意切換
- **文末**的「讀完這篇了嗎？」，按下去標記為已完成
- **系列詳情頁**每一章的單鍵按鈕
- **筆記列表的 Board 檢視**，把卡片拖到另一欄（見[筆記列表](/docs/guides/notes-list/)）

所有筆記都有閱讀狀態，不必屬於系列。

<Callout type="warn">
閱讀狀態存在瀏覽器的 localStorage，不寫進筆記檔，也不會跨瀏覽器或跨裝置同步。清掉網站資料就會歸零。`view` 與 `build`／`serve` 的產物都能用，部署成靜態站後，每位讀者各自記錄自己的進度。
</Callout>

## 系列頁與進度條

`/series` 列出所有系列與整體進度，點一列進入系列詳情 `/series/<id>`。詳情頁有：

- 章節數、已完成、閱讀中、未開始的統計，以及完成百分比
- 進度條，旁邊寫著「下一章：…」，全部讀完時顯示「已全部讀完」
- 依 `slugs` 順序排列的章節，每章有序號與目前狀態
- 「在筆記列表中篩選」：開 `/notes?series=<id>`
- 「重設進度」：把這個系列所有章節改回未開始，會先問一次

進度的分母是章節總數，分子是已完成的章數。閱讀中不算完成。

### 單鍵推進

詳情頁每章右側的按鈕依目前狀態變化，按一下推到下一個狀態：

| 目前 | 按鈕 | 按下後 |
| :-- | :-- | :-- |
| 未開始 | 開始閱讀 | 閱讀中 |
| 閱讀中 | 標記完成 | 已完成 |
| 已完成 | 重設 | 未開始 |

## 繼續閱讀

系列的「下一篇」是第一個閱讀中的章節；沒有的話是第一個未開始的章節。這個規則用在：

- **儀表板的系列卡**：每個系列一條進度，「開始閱讀」或「繼續閱讀」直接跳到下一篇
- **系列詳情頁**的「下一章」
- **Sidebar** 的系列區段，每個系列旁顯示已完成／總章數

讀系列裡的一篇筆記時，文末會有系列導覽：系列名稱、目前是第幾章、逐章的狀態，以及上一章／下一章的連結。

## 資料檔當一章

`slugs` 裡寫 `view:<路徑去副檔名>`，plugin 渲染的資料檔頁就成為系列的一章。它和筆記一視同仁：有序號、計入進度分母，在詳情頁標著「資料檔」。

和筆記的差別：資料檔頁沒有頁首的三段切換與文末的完成按鈕，打開它也不會自動變成閱讀中。它的狀態在系列詳情頁用單鍵按鈕推進。

資料檔頁不會出現在 `/notes` 列表，所以以系列篩選筆記時，篇數可能少於章節數。
