AI 生成簡報時不會每頁重新設計版面，而是「選頁填字」：判斷這一頁的內容是什麼型態，挑一個對應的原子，把資料填進去。這頁說明它從哪些選項裡挑，方便你讀懂生成結果，或在對話裡指定想要的版型。

## 6 種外框版型

| 版型 | 名稱 | 用途 |
| :-- | :-- | :-- |
| 封面 | `cover` | 標題、副標與議程 |
| 章節分隔 | `section` | 大編號加章節名，刻意留白 |
| 引言 | `quote` | 一句金句與出處 |
| 結語 | `closing` | 三項回顧與行動呼籲 |
| 全幅視覺 | `full-visual` | 嵌入筆記既有的互動元件，可兩幅並排 |
| 內容頁 | `custom` | 內容頁的主力，放原子 |

`custom` 以外的五種結構固定，由系統渲染，AI 只填欄位。內容頁的編號、標題、註腳、提示框等外框也由系統畫，AI 只決定內容區放什麼。

## 29 個原子

原子分兩層：

| 層 | 數量 | 怎麼用 |
| :-- | :-- | :-- |
| 整頁級 | 15 | 一頁一個，獨佔內容區 |
| 組合級 | 14 | 可以獨佔一頁，也可以兩三個並排 |

### 整頁級

| 原子 | 元件 | 內容長這樣時用它 |
| :-- | :-- | :-- |
| 開場濃縮 | `<Summary>` | 全篇論點濃縮，配佐證數字 |
| 主張三支柱 | `<Triad>` | 一個主張加三個支撐點 |
| 決策記錄 | `<Decision>` | 做了什麼決定、否決了哪些選項 |
| 交叉推論 | `<Cross>` | 兩個角度疊起來推出新看法 |
| 定位矩陣 | `<Quadrant>` | 很多項目擺到兩個維度上 |
| 取捨光譜 | `<Spectrum>` | 幾個項目落在一條軸的兩極之間 |
| 強度矩陣 | `<Heatmap>` | 列 × 欄的強度分布，例如支援度、成熟度 |
| 分層堆疊 | `<Layers>` | 上下依賴的層級 |
| 角色關係 | `<Roster>` | 一個中心加一圈沒有先後的角色 |
| 章節導覽 | `<Contents>` | 簡報中途回頭標示「走到哪了」 |
| 累計拆解 | `<Waterfall>` | 總數一段一段累積出來 |
| 佔比條 | `<Share>` | 一個整體被分掉的比例 |
| 排序榜 | `<Ranking>` | 有名次的排序 |
| 前後對比 | `<BeforeAfter>` | 同一組指標的兩個時點 |
| 風險研判 | `<Risk>` | 風險、影響與緩解 |

### 組合級

`<Rows>` 清單、`<Cards>` 卡片、`<Stages>` 流程階段、`<Kpi>` 頭條數字、`<Table>` 表格、`<Compare>` 兩案對決、`<Code>` 程式碼、`<Terminal>` 終端機、`<Frame>` 視窗外框、`<Annotate>` 標註、`<Chart>` 圖表、`<TagCloud>` 詞雲、`<LogoRow>` 技術組合、`<Mark>` 行內螢光筆。

## 選型規則

<Callout>
**同一份簡報裡，整頁級原子不會重複。** 15 個足夠撐起 10–14 頁而頁頁不同；不夠用時，AI 會合併頁面，而不是重用同一個原子。
</Callout>

每個內容頁依這個順序試，不跳級：

1. 一個整頁級原子。大部分內容頁到這裡就結束
2. 挑不到，就用一到兩個組合級原子並排
3. 仍挑不到，才自己寫版面，並在規劃裡寫明理由

自寫版面有兩個正當理由：系統沒有對應的元件（例如系統架構圖、拓撲圖），或內容本身有強烈的形狀、拆進通用原子會讓讀者少讀到一個論點。

## 圖表的限制

- 一張圖最多 3 個系列，圓環圖最多 3 片，超過就拆成多張小圖或改用表格
- 不用雙 Y 軸
- 數值直接標在圖上。投影片沒有滑鼠懸停，不能只靠 tooltip
