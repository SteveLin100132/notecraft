主區最上方那一列是頁籤列，行為類似編輯器的頁籤。打開一篇筆記（`/notes/…`）或一個資料檔頁（`/view/…`）就會多一個頁籤；儀表板、列表、系列、設定這些頁面不會產生頁籤，但頁籤列一樣顯示，方便跳回去。

## 開啟與切換

- 新頁籤插在目前頁籤的右側
- 從列表、Sidebar、`⌘K` 打開一篇已經開著的筆記，會切到那個頁籤，不會重複開
- 切回一個頁籤時，會捲回上次讀到的位置。網址帶 `#標題` 錨點時以錨點為準
- 未固定的頁籤最多 20 個。超過時自動關掉最久沒用的那個，並跳出提示
- 筆記檔被刪除或搬移後，對應的頁籤會在之後的頁面載入時自動移除；只改標題的話，頁籤上的標題會跟著更新

## 滑鼠操作

| 操作 | 結果 |
| :-- | :-- |
| 點頁籤 | 切換過去 |
| 點 ✕、滑鼠中鍵 | 關閉頁籤 |
| `⌘`／`Ctrl`＋點擊 | 在新的瀏覽器分頁開啟 |
| 拖曳 | 調整順序。固定區與一般區各自排序，不能拖過界 |
| 右鍵 | 開啟選單 |

右鍵選單有：關閉、關閉其他、關閉右側、全部關閉、固定頁籤（已固定時是取消固定）、複製連結、在新視窗開啟。

**固定**的頁籤排在最前面，✕ 換成圖釘，「關閉其他」「全部關閉」與 `⌥W` 都不會關掉它；要關先取消固定。

關掉目前這個頁籤時，會跳到右邊的頁籤，沒有就跳左邊，都沒有就回 `/notes`。

## 鍵盤快捷鍵

| 按鍵 | 動作 |
| :-- | :-- |
| `⌥.` | 下一個頁籤（到尾端會繞回第一個） |
| `⌥,` | 上一個頁籤 |
| `⌥W` | 關閉目前的頁籤 |
| `⌥⇧T` | 重開剛關閉的頁籤（最多記 10 個） |

Windows 與 Linux 上 `⌥` 是 `Alt`。游標在輸入框裡時這些按鍵不會被攔下。

焦點在頁籤列上時，還可以用 `←` `→` 移動、`Home`／`End` 跳到頭尾、`Delete` 或 `Backspace` 關閉、`⇧F10` 開右鍵選單。

## 全部頁籤

頁籤多到放不下時，頁籤列可以橫向捲動（滑鼠滾輪也行）。右側的按鈕打開「全部頁籤」下拉：

- 輸入文字篩選頁籤
- 固定的頁籤分在「已固定」一區
- 「重開剛關閉的」等同 `⌥⇧T`
- 「全部關閉」關掉所有未固定的頁籤

`⌘K` 指令面板最上方也有「已開啟的頁籤」一區，可以用搜尋的方式切換。

## 手機與其他

- 寬度在 860px 以下時頁籤列隱藏，頁首右上角改成一個顯示頁籤數的按鈕，點開是底部抽屜
- 簡報頁 `/present/…` 不顯示頁籤列
- 頁籤清單存在瀏覽器的 localStorage，`view` 與 `build`／`serve` 都能用。用 `notecraftapp` 開不同的筆記資料夾時，頁籤清單依工作區分開
