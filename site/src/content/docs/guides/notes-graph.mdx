Graph 是 `/notes` 的第五個檢視，把筆記畫成節點、把筆記之間的關聯畫成線。用它可以看出哪些筆記是大家都連過去的樞紐、哪些筆記從來沒被連到、哪些主題聚在一起。

從頁首的分頁切到 **Graph**，或直接開 `/notes?view=graph`。也可以在設定頁把它設成「預設 view」。

## 兩種關聯模式

Toolbar 左側的「關聯依據」切換模式。兩種模式是同一批節點，切換時節點會移動到新的位置。

| 模式 | 畫的是什麼 | 適合 |
| :-- | :-- | :-- |
| 文件 | 筆記之間實際寫下的關聯，線有方向 | 找樞紐、找孤島、看一篇筆記牽動哪些筆記 |
| 標籤 | 筆記與它的標籤，筆記之間不連線 | 看主題怎麼分群、哪些筆記橫跨幾個主題 |

## 文件模式：哪些寫法會變成線

線的方向一律是「寫下關聯的那一篇 → 被參照的那一篇」，箭頭指向被參照的一方。

| 種類 | 線型 | 怎麼產生 |
| :-- | :-- | :-- |
| 定義引用 | 實線 | 以 `:ref[文字]{id="…"}` 引用另一篇筆記裡的定義 |
| 定義嵌入 | 虛線 | 以 `::include{id="…"}` 嵌入另一篇筆記裡的定義 |
| 站內連結 | 點線 | 一般連結，見下表 |
| 系列順序 | 點劃線 | 同一個系列裡相鄰的兩章，前一章 → 後一章 |

站內連結認得這幾種寫法：

| 寫法 | 例 |
| :-- | :-- |
| 站內路徑 | `[快取](/notes/http-caching)`、`[API](/view/api/orders.openapi)` |
| 相對的筆記檔 | `[規格](../spec/overview.md)` |
| JSX 或 HTML 的 `href` | `<a href="/notes/http-caching">` |
| 筆記內嵌資料檔 | `<PluginView src="api/orders.openapi.json" />` |
| 資料檔的「回到來源筆記」 | 資料檔 `meta.backTo` 指向的筆記（線由資料檔指向筆記） |

程式碼區塊、行內程式碼與註解裡的連結不算，圖片也不算。連到不存在的筆記、連到站外的連結會被略過。

兩篇之間有多種或多次關聯時合成一條線：線越粗代表次數越多，線型取次數最多的那一種。定義引用與定義嵌入以「幾個不同的定義」計，同一個定義在一篇裡引用十次仍算一次；站內連結以出現次數計。

### 節點

- 圓形是筆記，圓角方塊是資料檔。資料檔只有在和畫面上的筆記有關聯時才出現
- 被越多篇筆記連入，節點越大，分四級：0–1、2–3、4–7、8 篇以上
- 沒有任何關聯的筆記是**孤島**，依目前的著色分組聚成小團，排在主圖外圍

## 標籤模式

全站筆記數最多的 8 個標籤是樞紐，等距排成一圈；筆記圍著自己的標籤，帶多個標籤的筆記落在幾團之間，以細線連到各自的標籤。

只帶其他標籤的筆記歸在「其他標籤」，完全沒有標籤的歸在「未加標籤」。點樞紐會只看那個標籤的筆記（等同從 Sidebar 點該標籤），並留在 Graph。

## Toolbar

| 控制 | 作用 |
| :-- | :-- |
| 關聯依據 | 文件／標籤 |
| 著色 | 依資料夾、系列、標籤，或不著色。分組超過 8 個時，節點數最多的 8 組有顏色，其餘是灰色的「其他」 |
| 邊 | 四種關聯各自開關（只在文件模式）。只影響顯示，節點不會重新排列 |
| 顯示孤島 | 關掉後只留有關聯的筆記 |
| 搜尋 | 比對標題、資料夾與標籤。符合的節點保持原色並顯示標題，其餘淡出；不會把節點濾掉 |

這些選擇（搜尋字串除外）存在瀏覽器裡，下次進 Graph 會沿用。

Sidebar 的資料夾、系列、標籤篩選照常有效：Graph 只畫符合的筆記，並重新排列。

## 操作

| 操作 | 結果 |
| :-- | :-- |
| 拖曳空白處 | 平移 |
| 滾輪 | 以游標為中心縮放（25%–300%） |
| 右下角的按鈕 | 放大、縮小、符合視窗 |
| 滑過節點 | 它和直接相連的節點、線保持原色，其餘淡出；顯示標題、資料夾與連入連出數 |
| 滑過線 | 顯示兩端的筆記與各種關聯的次數 |
| 點筆記節點 | 在右側開 Drawer 預覽，再點一次關閉；`⌘`／`Ctrl`＋點擊在新分頁開啟筆記 |
| 點資料檔節點 | 前往該資料檔的頁面 |
| `Tab` | 依序聚焦節點，`Enter` 或空白鍵等同點擊 |

預設只有較大的節點顯示標題。放大到 150% 以上會顯示全部標題；節點超過 150 個時要放大到 240%。

<Callout>
Graph 需要 860px 以上的視窗寬度。較窄的畫面會顯示說明，並提供切回 List 的按鈕。
</Callout>

## 圖上沒有線的時候

文件模式下，如果畫面上的筆記之間完全沒有關聯，Graph 會改顯示建立關聯的四種寫法，並提供切到標籤模式的按鈕。標籤模式不需要任何連結就能看。
