NoteCraftApp 是為寫技術筆記的人做的筆記工作台。它直接讀你專案裡的 md／mdx 資料夾，用 `npx notecraftapp view ./docs` 一行指令就能在瀏覽器打開三欄工作台，不需要把筆記搬進任何特定格式或服務。

## 它做什麼

- **工作台**：Rail、資料夾樹、主區三欄。筆記列表有 List／Board／Table／Timeline 四種 view，單擊一列在右側 Drawer 預覽
- **儀表板**：筆記總數、閱讀狀態、AI 待生成、寫作頻率、最近更新、系列進度、標籤分布、更新日誌，另有「更新月曆」與「AI 佇列」兩個 Tab
- **系列與閱讀進度**：多篇筆記串成有順序的閱讀路徑
- **⌘K 指令面板**：跨頁跳轉，含全文搜尋
- **筆記頁籤**：開過的筆記與資料檔留在最上方的頁籤列
- **AI 視覺化**：在 MDX 裡用 `@ai-visualize` 標記描述想要的圖，Claude Code 生成 React 互動元件並寫回筆記
- **筆記轉簡報**：一篇筆記轉成 16:9 多頁簡報，筆記裡的互動元件原樣搬進投影片
- **Plugin**：結構化 JSON 資料檔（ER 圖、OpenAPI 文件）交給可安裝的渲染器畫成頁面

## 為什麼要它

一般的筆記工具只能顯示文字。想把一段流程講清楚、把兩個方案並排比較，或讓讀者親手拖動看兩種策略的差異，通常只能貼靜態圖或放連結。

NoteCraftApp 讓筆記裡的知識可以被看見、被操作：

- 在筆記裡用自然語言描述一張圖，由 AI 生成可互動的元件，嵌在原本的位置
- 內文欄放不下的寬元件，可以放大到全螢幕畫布平移、縮放，互動照樣保留
- 同一份筆記轉成簡報時，互動元件在播放時照樣能點、能拖

寫筆記、補圖表、轉簡報，都在同一本筆記裡完成。

## 不需要改寫既有筆記

- frontmatter 全部選填。缺標題就從 H1 或檔名抓，缺日期就從檔案時間抓
- 巢狀資料夾直接對到網址，例如 `guides/oauth/flow.mdx` 對到 `/notes/guides/oauth/flow`
- MDX 裡用相對路徑寫的圖片會自動解析

AI 生成、簡報與 Plugin 都是選用的。只想用工作台讀筆記，裝 Node 就夠了，見[三層體驗](/docs/intro/three-layers/)。
