標籤寫在筆記的 frontmatter，`.md` 與 `.mdx` 都可以用。沒寫就是沒有標籤，其他功能照常。

## frontmatter 寫法

```yaml title="guides/http-cache.mdx"
---
title: "HTTP 快取"
tags: ["http", "cache"]
---
```

也可以寫成 YAML 清單：

```yaml
tags:
  - http
  - cache
```

- `tags` 是字串陣列。數字樣的標籤要加引號，例如 `"2026"`
- 中文、空白都可以用
- 大小寫有別：`React` 和 `react` 寫在不同筆記裡，會被當成兩個標籤

## 正規化規則

透過介面寫入標籤時，會依序整理：

1. 去掉每個標籤前後的空白
2. 去掉空字串
3. 同一篇內不分大小寫去重，保留第一次出現的寫法

<TagNormalize />

這套規則只在介面寫入時套用：新增筆記、在筆記頁改標籤、在 `/tags` 重新命名。你在編輯器裡手寫的 frontmatter 不會被自動整理，照原樣讀取。

跨筆記的大小寫不會被統一。想把 `react` 併進 `React`，用 `/tags` 的重新命名。

## 在工作台哪裡看到

| 位置 | 呈現 | 點下去 |
| :-- | :-- | :-- |
| 筆記頁標題下方 | 標籤 chip | `/notes?tag=<標籤>` |
| `/notes` 列表 | List 每列顯示前 2 個（其餘以 +N 表示），Table 有標籤欄，右側 Drawer 的 Metadata 列出全部 | Drawer 裡的標籤開 `/notes?tag=<標籤>` |
| `/notes` List 的「標籤」分組 | 依每篇的**第一個**標籤分組 | — |
| Sidebar「其他」區的「標籤」 | 全站標籤數 | `/tags` |
| 儀表板「標籤分布」 | 最常用的 11 個標籤，面積代表篇數 | 方塊開 `/notes?tag=<標籤>`；「其他 N 個」開 `/tags` |
| `⌘K` 指令面板 | 「標籤」分區，輸入後最多 4 個 | `/notes?tag=<標籤>` |

### ?tag= 篩選

`/notes?tag=React` 只列帶這個標籤的筆記，可以和 `?folder=`、`?view=` 等參數組合。值要與標籤完全相同，包括大小寫。其他參數見[網址參數](/docs/reference/url-params/)。

`/notes` Toolbar 右側的搜尋框也會比對標籤，但只是過濾當頁列表，不進網址。

### /tags 頁

## 在介面上編輯

只有 `notecraftapp view` 能編輯。`serve` 與 `build` 的產物裡，筆記頁的標籤只是連結，`/tags` 也沒有編輯按鈕。

### 單篇筆記

筆記頁標題下方的標籤列：

| 操作 | 結果 |
| :-- | :-- |
| 在「新增標籤」輸入後按 `Enter` | 加入標籤。輸入時會列出全站既有標籤供選，`↑` `↓` 選取 |
| 點標籤上的 ✕ | 移除 |
| 輸入框空白時按 `Backspace` | 移除最後一個標籤 |

每次變更都會立刻寫回這篇的 frontmatter，`updatedAt` 改成今天。

### 全站：重新命名與刪除

`/tags` 每一列右側有「重新命名」與「刪除」，作用於所有用到這個標籤的筆記：

| 動作 | 行為 |
| :-- | :-- |
| 重新命名 | 列上直接改名，`Enter` 送出、`Esc` 取消，再於確認框確認 |
| 合併 | 新名稱和既有標籤完全相同時，確認框改為「合併標籤」。同時有兩個標籤的筆記會去重，只留一個 |
| 刪除 | 從每一篇的 `tags` 移除，筆記本身不動。要先勾選「我了解…」才能按「永久刪除」 |

<Callout type="warn">
重新命名與刪除會改動多個檔案，介面上沒有復原。動手前先 commit，出錯時用 git 還原。
</Callout>

受影響筆記的 `updatedAt` 都會改成今天，它們因此會出現在儀表板的「最近更新」與本週更新的數字裡。寫入的其他細節見[在介面新增與編輯](/docs/guides/editing/)。
